## 路径一：重进下载模式后我用 heimdall 刷（Linux，无需 Windows）

**你需要做**：退出下载模式再重进（让 bootloader 的 USB 栈重置）
> 长按 **电源 10~20 秒**断电 → 等 5 秒 →
> 按住 **音量下 + Home + 电源** → 出现警告页 → 按 **音量上**

**建议同时做**：把数据线**换到电脑后置 USB 2.0 口**（不要走 HUB）。
这台机器的下载模式是 USB 2.0 High-Speed，走 xHCI + HUB 时握手容易失败。

**然后我执行**（已备好 raw 镜像）：
```bash
cd /home/duanjb666/deepseek/G9209-fix
sudo heimdall flash --no-reboot \
  --BOOT     stock-extract/boot-stock.img \
  --SYSTEM   stock-extract/system-raw.img
```
> 只刷 BOOT + SYSTEM。**不刷 USERDATA**（10 GB，之前两次掉线都在这量级；
> 原厂首次开机会自己重建 /data）。**不刷 RECOVERY**（保留 TWRP 作退路）。
> 若想连 RECOVERY 一起刷成原厂，加 `--RECOVERY stock-extract/recovery-stock.img`。

```
    ├── boot.img / system.img / recovery.img / userdata.img   (已解包)
```
另有一份同样的四件套在 `~/下载/`。

**Odin 操作**：
| 槽位 | 文件 |
|---|---|
| AP | `AP_G9209KEU2ERI2_..._meta.tar.md5` |
| BL | `BL_G9209KEU2ERI2_..._ship.tar.md5` |
| CP | `CP_G9209KEU2ERI2_..._ship.tar.md5` |
| CSC | `CSC_CTC_G9209CTC2ERI2_..._ship.tar.md5` |

选项：`Auto Reboot` ✅ / `F.Reset Time` ✅ / **不要勾 `Re-Partition`**
（若 Odin 索要 PIT，用 CSC 里的 `ZEROFLTE_CHN_CTC.pit`）

> ⚠️ 刷 BL（bootloader）风险高于只刷 AP。若只想让基带跑起来做基准，
> **只刷 AP + CP + CSC 也够**（保留现有 bootloader）。
